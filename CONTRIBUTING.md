# Contributing

Issues and pull requests are welcome. Please describe the problem, the expected
behavior, and the steps to reproduce it. Include browser and Node.js versions
when relevant. Do not post API keys, private page content, or other secrets.

For code changes:

1. Create a branch for the change and explain its purpose in the pull request.
2. Run `npm test` with Node.js 22 or newer and report the results.
3. For extension behavior changes, describe the browser and manual checks used.
4. Update documentation or the changelog when the change warrants it.
5. Ensure that you have the right to submit your contribution under the
   project's [MIT license](LICENSE).

The commit history and pull requests record future contributions. The initial
source archive did not include a historical contributor list or Git history.
