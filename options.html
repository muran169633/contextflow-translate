ContextFlow Translate

Connection and translation preferences

Bring your own model, translate in context, and build a reliable terminology glossary.

1. AI connection / API 配置

Supports OpenAI-compatible chat/completions endpoints, including most personal API gateways and local Ollama-compatible servers.

Use your provider's base URL ending in /v1, or paste the full /chat/completions URL. HTTPS required except localhost.
Use exactly the name exposed by your provider.
Stored locally in your Chrome profile; never pasted into the webpage DOM.

2. Translation quality / 翻译质量

Fidelity and terminology matter more than writing something that merely sounds fluent.

Limits provider costs. Default: 50 paragraphs.
One term per line: source => preferred translation. Up to 60 terms sent per request. Lines beginning with # are comments.
Privacy: when you press Translate, selected page paragraphs, the page title, surrounding text, and glossary entries are sent directly to the AI endpoint you chose. Do not translate confidential pages using an untrusted provider. The API key is kept locally but is not encrypted with an app-specific password.
Configure your API endpoint and save. Chrome will ask permission to contact that API domain.
